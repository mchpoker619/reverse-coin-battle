# 逆轉金幣 桌面對戰（Python / pygame）

2D 俯視的逆轉金幣（逆転バリバリバース）對戰遊戲。規則依 **isn_ver.1**，內建全部 101 枚金幣資料。

## 安裝與執行

1. 安裝 Python 3.9 以上（https://www.python.org/ ，安裝時勾選「Add Python to PATH」）
2. 安裝 pygame-ce（支援最新版 Python 的 pygame）：
   ```
   python -m pip install pygame-ce
   ```
3. 在本資料夾執行：
   ```
   python reverse_coin.py
   ```
   Windows 也可以直接雙擊 `執行遊戲.bat`。

## 遊戲流程（官方取扱説明書 Ver.1.1.2 エキスパートルール）

1. **選模式**：雙人對戰（同一台電腦輪流）或對戰電腦
2. **組隊**：從 101 枚中選 1～3 枚（同一隊不可重複），OX 合計 ≤ 15,000（メタ幣以 M 值計，官方 p.7）
3. **猜拳**：勝方選陣營（秩序白／極限黑），再擲金幣決定先攻
4. **對戰**：輪流擊球，淘汰對手全部金幣就獲勝

## 新規則（限時）

- **每回合 18 秒**：要在 18 秒內完成出手（包含精準度），否則視同放棄、換對方進攻；畫面左上有倒數。
- **全場 8 分鐘**：時間到時（等當下回合結束），比雙方開場隊伍的 M 值合計，**較少**的一方獲勝，相同為平手。
- 規則說明畫面改成圖解（`rules_img/` 資料夾，可自行替換圖片）。

## 主選單

主畫面只有「開始遊戲」「遊戲設定」「離開」：開始遊戲裡選規則（專業 3V3／標準 1V1／簡易 1V1）、場地（A2／A3）和模式（雙人／對戰電腦）；電腦強度、操作模式、旋轉、出界、音效音樂、規則說明都在遊戲設定裡。

## 擊球操作

| 步驟 | 操作 |
|---|---|
| ① 選金幣 | 點自己的金幣選擇，再點一次（或 Space）確定；Tab 切換 |
| ② 後拉發射 | 在場上按住滑鼠往反方向拉（像彈弓），拉越長越大力（拉約 200 px＝100%），放開進入精準度；鍵盤 ←→ 方向、↑↓ 力量、Space 發射 |
| ②’ 點選式（V 鍵切換） | 移動滑鼠對準 → 點場地或右下「確定方向」鎖定方向 → 力量條點一下 → 精準度；「← →」每點 0.5°（← 往畫面左邊、→ 往右邊）、按住連續轉；鎖定後點哪裡都不會改方向，滑鼠移到右側面板時方向也不會跟著跑 |
| ④ 精準度條 | 停在中間綠區＝PERFECT 不偏；一離開綠區就至少偏 5°，越靠邊越大，最邊緣以發射方向為基準左右各偏 70°，並帶弧線 |
| 旋轉 | 出手前點面板「◀ 左旋／右旋 ▶」按鈕，或按 Z／X，左右各 3 段；開場畫面可關閉旋轉；輔助線會跟著旋轉彎曲（依目前力量預測，還沒選力量時以 60% 估算）；旋轉越強，精準度 PERFECT 綠區越窄（每段縮 20%，3 段剩 40%） |
| 輔助線 | 右上角「輔助線」按鈕或 H 鍵開關；關閉時改用三角箭頭決定方向 |

瞄準輔助線（黑框粗線）：**青色**＝自己的路線與撞擊位置、**橘色**＝對手被撞去的方向、**綠色**＝自己撞後分開的方向。對手金幣上的**紅色弧線**是リバースポット（開關所在方向與正對面）。

## 判定（官方規則＋香港大賽規則）

- **防守方彈起翻成對方顏色** → OUT
- **防守方彈起仍是自己顏色** → OX 對決：守 ≥ 攻 セーフ（平手守方勝），由主人放回**撞擊前的位置**、只能轉方向不能移動；守 ＜ 攻 OUT
- **メタ幣**：被打到彈起時中央核心會翻面，OX 對決用**翻面後**的數值（例：レオウ白面 8000 被打 → 用黑面 4000 比）
- **防守方被撞出界、仍在裝填狀態** → Safe，由主人放回場內任何位置（離其他金幣 ≥ 1 枚直徑，Q／E 轉方向）
- **同時解除狀態**（攻擊方和對手一起彈起）：都變色或都沒變色 → 雙方 Safe；只有一方變色 → 那一方 OUT
- **自滅**：自己回合自己的金幣出界（含被自己撞出去的隊友）→ OUT；自爆翻成對方顏色 → OUT
- **自爆仍是自己顏色** → セーフ，放回撞擊前的位置；沒撞到任何金幣 → 無效攻擊
- **規則模式**（標題畫面切換）：專業 3V3（8 分鐘）／標準 1V1（5 分鐘、有 OX）／簡易 1V1（5 分鐘、不比 OX）
- **出界開關**（標題畫面）：關閉時撞框一律反彈，不會出界
- 開場擺放：自己的金幣直線間隔 1 枚、與對手間隔 6 枚
- 程式開頭 `OFFICIAL_RULES = False` 可改回 isn_ver.1 自訂規則（攻擊方翻色不淘汰、隊友出界放回）

## OX 對決畫面

每次判定時，場地中間會跳出對決畫面：
- **OX 對決**：攻擊方 vs 防守方的金幣與數值，顯示「≤／＞」與結果（平手會標示守方勝）
- **翻面！**：防守方翻成對方顏色時直接淘汰（不比 OX）
- 點擊或按 Space 可以跳過

## 場地

- 場地大小在「開始遊戲」裡選：**A2（420 × 594 mm，官方 A3 圖紙等比例放大 √2）** 或 **A3（297 × 420 mm，官方バリ場原尺寸，金幣剛好在圖紙印的圓圈裡）**；開局前選定，對戰中不能更改。兩種都是自己的金幣間隔 1 枚、與對手間隔 6 枚，金幣大小與手感相同（A2 比較不容易出界）
- 金幣直徑 **43 mm**，依實際比例縮放（1 mm = 1.65 px）
- 開場時金幣放在圖紙印好的圓圈裡（圓圈間隔 6 個），開關朝自己的右手邊

## 邊框（撞球檯式）三種情形

1. **出界**：垂直撞向邊框的速度 ≥ 450（大於翻轉門檻 280）→ 飛過邊框出界
2. **反彈**：速度不到 450 → 速度 ×0.7（減少動能）後反彈回場內；斜斜擦過也只會反彈
3. **反彈＋翻轉**：反彈時如果是**自己的リバースポット**撞到邊框，而且速度 ≥ 280（翻轉力道）→ 也會彈起翻轉

## 翻轉條件

- リバースポット（開關方向與正對面，各 ±13°）受到的撞擊速度 **≥ 280** 才會彈起；打在其他位置再大力也不會翻
- 彈起後落地正反面各 1/2

## 金幣碰撞（撞球式）

- 等質量彈性碰撞（回彈係數 0.95）：正面撞擊時出手的金幣幾乎停住，目標接手速度
- 切球時兩顆金幣約以 90° 分開

## 旋轉（撞球式）

- 金幣當成均勻圓盤計算轉動慣量，滑行時會轉、旋轉慢慢減速到停
- 帶旋轉滑行會走弧線（右旋往右彎、左旋往左彎），弱點方向也會跟著轉
- 撞到對手時接觸點摩擦會把旋轉傳過去（兩枚反方向轉，像齒輪），並把對手往側邊帶偏
- 帶旋轉撞邊框，反彈角度會改變（撞球的塞球效果）
- 精準度沒按準時也會多帶一點旋轉
- 瞄準時會顯示預測線：橘色＝目標金幣去向，綠色＝自己金幣分開的方向
- 高速時自動細分計算，避免穿透

## 遊戲中的模擬設定（可在程式開頭調整）

- **出界門檻**：`OUT_SPEED`（672.75，必定大於翻轉門檻，啟動時會檢查）、邊框回彈係數 `RAIL_REST`（預設 0.7）
- **翻轉力道**：`UNLOCK_SPEED`（金幣互撞，296.24）、`UNLOCK_RAIL`（弱點撞邊框，322）
- **金幣互撞**：`COIN_REST`（0.98）、接觸摩擦 `COIN_MU`（0.12）、出手金幣跟進力 `SHOOTER_MASS`（1.3）
- **旋轉**：每段 `SPIN_STEP`（7 rad/s）、減速 `SPIN_DECEL`（12 rad/s²）、弧線 `CURL_K`（0.03）、邊框摩擦 `RAIL_MU`（0.25）、沒按準額外旋轉 `ACC_SPIN`（6）、綠區縮小 `SPIN_PERF`（每段 20%）
- **弱點範圍**：`SPOT_HALF`（±14.1°）
- **落地顏色**：彈起後落地正反面各 1/2，跟力道無關（`FLIP_CHANCE` = 0.5）
- **上場數值**：用自己陣營那一面的 OX 值；預算才用 M 值

## 音效（可以自己換）

`sounds/` 資料夾：`coin_hit`（金幣碰撞）、`rail_hit`（撞邊框）、`flip`（翻面）、`bgm`（背景音樂）。
用同樣檔名覆蓋就能換，`.wav`／`.ogg`／`.mp3` 都可以；刪掉＝那個聲音靜音。音量在程式開頭 `VOLUME` 調整。
遊戲中右上「音效」「音樂」按鈕分開開關（N＝音效、M＝音樂）。

## 檔案
