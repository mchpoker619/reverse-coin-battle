規則圖解（官方 Ver.1.1.2）

完整文字規則
  • 賽前：每方 1～3 顆、同一隊不可重複；OX 合計 ≤ 15,000，メタ幣算 M 值（正＋反）÷2；上場看自己陣營那一面。猜拳勝方選陣營，擲金幣決定先攻。
  • 重新鎖定方向：彈起後 Safe 留在場內的金幣（防守方 OX 存活、攻擊方自爆沒變色）原地重新鎖定，弱點方向由攻擊方決定；被撞出場外 Safe 的金幣由攻擊方放回並決定方向（判定助手 v3）。
  • 簡易規則 EASY 1V1：每方 1 枚；彈起沒變色直接 Safe（不比 OX）；雙方同時翻成對方色＝平手、只有一方變色＝那一方 OUT。
  • 操作模式：彈弓式（按住自己的金幣往後拉、放開發射）或點選式（點金幣 → 對準點一下 → 力量條點一下 → 精準度）。標題畫面或對戰中工具列都能切換（V 鍵）。
  • 全場限時 8 分鐘：時間到時（等當下這一回合結束），比雙方開場三枚金幣的 M 值合計，合計較少的一方獲勝；相同為平手。畫面左上顯示全場剩餘時間。
  • 發射：點自己的金幣，按住畫面往反方向拉（像彈弓），拉越長越大力（上限 100%），放開後跑精準度條。每回合 18 秒內要完成出手，否則視同放棄、換對方進攻（畫面上方有倒數）。
  • 擊球：① 點自己的金幣，再點一次確定 ② 移動滑鼠瞄準（←→ 微調）點擊確定 ③ 力量條 ④ 精準度條：中間綠區＝PERFECT 不偏；一離開綠區就至少偏 5°，越靠邊越大，最邊緣以發射方向為基準左右各偏 70°，並帶弧線。Space／Enter 也可確定。輔助線：青色＝自己路線、橘色＝對手被撞去向、綠色＝自己分開方向；按 H 或「輔助線」按鈕可關閉，改用三角箭頭瞄準。
  • 翻轉：開關方向與正對面是リバースポット（紅色弧線）。撞擊力道 ≥ 翻轉門檻才會彈起，落地正反各 1/2。
  • 邊框：垂直撞擊 ≥ 出界門檻（必定大於翻轉門檻）→ 飛出界；不夠快 → 減速反彈；反彈時若是自己的リバースポット撞牆且力道夠 → 也會彈起翻轉。
  • 碰撞：撞球式，正面撞擊母球停住、切球約 90° 分開。
  • 音效／音樂：金幣碰撞、撞邊框、翻面各有不同音效，另有背景音樂；右上「音效」「音樂」按鈕分開開關（N 音效、M 音樂）。
  • 旋轉：出手前按 Z（左旋）／X（右旋）或面板按鈕，左右各 3 段。旋轉中的金幣會轉動、走弧線，弱點方向會跟著轉；撞到對手會把旋轉傳過去並把對手帶偏（齒輪效果）；帶旋轉撞邊框反彈角度會改變（塞球）。精準度沒按準也會多帶一點旋轉。旋轉越強，精準度 PERFECT 綠區越窄（每段縮 20%，3 段剩 40%）。
  • 組隊：先組隊（1～3 枚、不可重複）再猜拳選陣營，所以メタ幣能不能用到高的那一面要看猜拳。
  • 攻擊方：出手的金幣自己出界 → 淘汰。官方（預設）：自爆翻成對方色、自己的金幣（含隊友）在自己回合出界，都是自滅 OUT。isn_ver.1 自訂：這兩種不淘汰。彈起仍是自己顏色 → セーフ，原地重新鎖定。
  • 防守方：出界沒彈起 → 存活並由攻擊方安排回場（方向自由，Q／E 旋轉）；翻成對方顏色 → 淘汰；彈起仍是自己顏色 → 比 OX，守 ≥ 攻 存活（平手守方勝），存活的留在停下的位置原地重新鎖定（場外的由攻擊方放回）。
  • メタ幣：被打到彈起時中央核心會翻面，OX 對決看翻面後的數值（例：レオウ白面 8000 被打彈起 → 用黑面 4000 比）。
  • 場地：官方 A3 バリ場 297×420 mm，金幣直徑 43 mm、厚 8 mm。勝利：淘汰對手全部 3 枚。
